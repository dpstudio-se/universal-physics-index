# UPI & OdinOS Puter Module (`upi-puter-ui`)

A machine-readable, interactive Web UI and Puter OS module for the **Universal Physics Index (UPI)** engine and **OdinOS** kernel.

## Features

- **Puter.js Integration**: Runs seamlessly inside [Puter OS](https://github.com/HeyPuter/puter) with cloud storage (`puter.fs`), key-value persistence (`puter.kv`), and AI assistant (`puter.ai`).
- **DNA Sonification & Acoustic Generator**: Interactive 4-base harmonic sonifier (A4=440Hz, C4=261.63Hz, G4=392Hz, E4=329.63Hz) with 12-TET semitone calculations and Web Audio API real-time playback.
- **Digital Qudit Torus Search Visualizer**: Multi-torus register simulator visualizing computational/Fourier dual state probabilities.
- **UPI Status & Evidence Inspector**: Live scientific boundary inspector enforcing strict status tags (`EST`, `DER`, `HYP`, `STOP`, `ERR`, `SYM`) and confusion guards.
- **8 Hz Reference & Golden Ratio ($\phi \approx 1.618$) Aesthetic**: Vibrant dark-mode glassmorphism interface.

## Quick Start

### Standalone Server

```bash
python -m upi_puter_ui --port 8080
```

Open `http://localhost:8080` in your web browser.

### Puter OS Integration

Upload the module folder or `puter.manifest.json` to your Puter desktop host to register `Universal Physics Index — OdinOS` as a Puter desktop application.
